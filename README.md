# StudyMate

**StudyMate — Simple, useful tools for students.**

StudyMate is a student utility website designed to provide quick and easy-to-use tools for everyday academic needs.

## 🌐 Live Website

https://vidyadhari-ai.github.io/study-mate/

## ✨ Features

- 📊 CGPA Calculator
- 📈 SGPA Calculator
- 📝 Attendance Calculator
- 🔢 Percentage & Marks Calculator
- ⏱️ Study Timer
- 📱 Responsive design for desktop and mobile

## 🎯 Purpose

StudyMate brings commonly used student tools together in one simple and easy-to-use website.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
